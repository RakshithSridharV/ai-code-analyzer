============================================================
  ASTra — How to Run the Project
  AST-Native Code Intelligence Platform
============================================================

REQUIREMENTS
------------
- Python 3.10 or higher
- Node.js 18 or higher
- npm 9 or higher

------------------------------------------------------------
OPTION A: Run Without Docker (Recommended for Demo)
------------------------------------------------------------

STEP 1 — Start the Backend
  Open a terminal and run:

    cd backend
    pip install -r requirements.txt
    python app.py

  Backend will start at: http://localhost:5000

STEP 2 — Start the Frontend
  Open a second terminal and run:

    cd frontend
    npm install
    npm run dev

  Frontend will open at: http://localhost:5173

STEP 3 — Open in Browser
  Go to: http://localhost:5173
  Register an account and start analyzing code!

------------------------------------------------------------
OPTION B: Run With Docker (One Command)
------------------------------------------------------------

  Make sure Docker Desktop is installed and running, then:

    docker-compose up --build

  Frontend: http://localhost:80
  Backend:  http://localhost:5000

------------------------------------------------------------
QUICK DEMO — Paste this Python code to test:
------------------------------------------------------------

  def find_duplicates(arr):
      result = []
      for i in range(len(arr)):
          for j in range(i + 1, len(arr)):
              if arr[i] == arr[j]:
                  result.append(arr[i])
      return result

  Expected result:
    Time Complexity  : O(n^2)
    Space Complexity : O(n)
    Cyclomatic       : 4 (Moderate)
    Anti-patterns    : None
    Quality Score    : Inefficient (consider using a set)
